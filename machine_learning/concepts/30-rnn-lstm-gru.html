30RNN, LSTM & GRU

Recurrent hidden state propagation, the vanishing gradient problem, and how LSTM/GRU gates (forget, input, output) preserve long-range signal.

Theory

Vanilla RNN & the Vanishing Gradient Problem

A recurrent network processes a sequence by maintaining a hidden state h_t that is updated at every timestep from the current input and the previous hidden state: h_t = tanh(W_xh · x_t + W_hh · h_{t-1} + b). The same weight matrices are reused at every timestep — weight sharing across time, analogous to weight sharing across space in a CNN — which is what lets an RNN process sequences of arbitrary length with a fixed parameter count. The problem surfaces in backpropagation through time (BPTT): the gradient of the loss with respect to an early hidden state h_1 is a product of Jacobians across every intermediate timestep, ∂h_T/∂h_1 = Π diag(1 − h_t²) · W_hh. Each factor is a matrix with spectral radius typically well below 1 (the tanh derivative is at most 1 and near 0 whenever the unit is saturated, and W_hh is rarely initialized with spectral radius exactly 1), so the product shrinks geometrically with sequence length — vanishing gradients. If instead the spectral radius exceeds 1, the same product grows geometrically — exploding gradients, which is more visible (loss goes to NaN) and easier to patch with gradient clipping, but vanishing gradients silently prevent the network from ever learning dependencies more than roughly 10–20 steps back, no matter how long training runs.

LSTM: The Constant Error Carousel

Hochreiter & Schmidhuber's 1997 fix separates a cell state c_t from the hidden state and updates it additively rather than through a squashing nonlinearity at every step:

f_t = σ(W_f x_t + U_f h_{t-1} + b_f)  (forget gate)
i_t = σ(W_i x_t + U_i h_{t-1} + b_i)  (input gate)
o_t = σ(W_o x_t + U_o h_{t-1} + b_o)  (output gate)
g_t = tanh(W_g x_t + U_g h_{t-1} + b_g)  (candidate)
c_t = f_t ⊙ c_{t-1} + i_t ⊙ g_t
h_t = o_t ⊙ tanh(c_t)

Because c_t depends on c_{t-1} through an elementwise multiply-and-add rather than a matrix multiply followed by a squashing nonlinearity, the dominant backward path ∂c_t/∂c_{t-1} ≈ f_t lets gradient flow through many timesteps almost unattenuated as long as the network learns to keep the forget gate near 1 — this is the "constant error carousel." The gates are themselves learned functions of the input, so the network can choose, per-timestep and per-unit, what to remember and what to overwrite. A well-known practical trick (Jozefowicz et al., 2015) is initializing the forget gate bias to +1 or +2 so the gate starts near "remember everything" and the optimizer only has to learn what to forget, rather than fighting an initial bias toward forgetting everything.

GRU: A Leaner Alternative

Cho et al. (2014) proposed the Gated Recurrent Unit, which merges the forget and input gates into a single update gate z_t and drops the separate cell state entirely, folding memory directly into the hidden state:

z_t = σ(W_z x_t + U_z h_{t-1} + b_z)
r_t = σ(W_r x_t + U_r h_{t-1} + b_r)  (reset gate)
h̃_t = tanh(W_h x_t + U_h (r_t ⊙ h_{t-1}) + b_h)
h_t = (1 − z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t

This costs roughly 25% fewer parameters than an LSTM of the same hidden size (3 weight matrices instead of 4 per direction) and the analogous carousel term is ∂h_t/∂h_{t-1} ≈ (1 − z_t), giving similar long-range gradient preservation via a single gate rather than an interaction of forget and output gates. Chung et al.'s 2014 empirical comparison found GRU and LSTM broadly comparable on most sequence tasks, with LSTM sometimes retaining an edge on tasks that need to count or copy over very long spans, plausibly because the explicit, unbounded cell state is a cleaner "memory slot" than a hidden state that is also the direct output.

Production Reality

Even gated architectures still need gradient clipping (typically clipping the global norm to 1–5, e.g. torch.nn.utils.clip_grad_norm_) because gating solves vanishing gradients, not exploding ones. Training uses truncated BPTT — backpropagating only through a fixed window (commonly 20–200 steps) rather than the full sequence, trading the ability to learn dependencies beyond the window against the memory cost of caching every intermediate activation for the backward pass. cuDNN historically shipped fused, hand-optimized LSTM/GRU kernels (cudnn.LSTM) that were 5–10× faster than a naive Python-level per-timestep loop on GPU, which mattered enormously before frameworks got good at kernel fusion. Today, for most NLP and long-sequence modeling, Transformers have displaced RNNs because self-attention parallelizes over the sequence dimension (all timesteps computed simultaneously) whereas an RNN is inherently sequential — one step must finish before the next begins, which caps GPU utilization regardless of batch size. RNNs and LSTMs remain the pragmatic choice, though, for streaming/online inference (constant O(1) memory and compute per new timestep, versus a Transformer's growing O(T) attention cache), classical time-series forecasting (e.g. Amazon's DeepAR), and any low-latency edge deployment where a full attention mechanism is too expensive.

Key Takeaways

  • Vanishing gradients are a spectral-norm story, not a mysterious black box — the BPTT gradient is a product of ~T Jacobians diag(1−h²)·W_hh; if that product's dominant eigenvalue is below 1 (the common case), the gradient shrinks geometrically, so a vanilla RNN effectively cannot learn dependencies past roughly 10–20 steps regardless of training time.
  • Initialize the LSTM forget-gate bias to +1 or +2 (Jozefowicz et al., 2015) so the gate starts near "remember everything" — PyTorch's nn.LSTM zero-initializes all biases by default, so this is a manual fix worth applying on tasks with long dependencies, not something you get for free.
  • GRU has ~25% fewer parameters than LSTM at the same hidden size (3 gate matrices vs. 4) and trains faster per step — Chung et al. (2014) found comparable accuracy on most tasks, with LSTM's separate, unbounded cell state occasionally winning on tasks that require precise long-range counting or copying.
  • Gating fixes vanishing gradients, not exploding ones — production LSTM/GRU training still needs gradient clipping (global norm clipped to 1–5 via clip_grad_norm_); skipping it is a common source of NaN losses even with gated architectures.
  • Truncated BPTT (window ~20–200 steps) is a memory/bias tradeoff — full backprop through a 10,000-step sequence means caching 10,000 timesteps of activations; truncating saves memory but hard-caps what dependency length the model can ever learn.
  • Transformers won on parallelism, not universally on quality — self-attention computes all timesteps at once (great GPU utilization) while an RNN is inherently sequential; RNNs/LSTMs remain the pragmatic choice for streaming inference with O(1) per-step memory, classical time-series models like DeepAR, and latency-constrained edge deployment where a full attention cache is too expensive.
