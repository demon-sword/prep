44Residual Learning

Why very deep networks get worse instead of better, and how skip connections fix optimization, preserve gradient structure, and turn one deep net into an ensemble of shallow paths sharing a single residual stream.

Theory

Degradation Is an Optimization Failure, Not Overfitting

The founding observation of He et al. (2015, "Deep Residual Learning for Image Recognition") is routinely misremembered as a vanishing-gradient story, but the paper's evidence points somewhere more specific. On CIFAR-10, a 56-layer plain convolutional network has higher training error than a 20-layer plain network — not just higher test error. If depth were causing overfitting, the deeper net would fit the training set better and generalize worse; instead it fits worse, which rules out overfitting and indicts the optimizer. The same inversion appears at the extreme: a 1202-layer plain network trains worse and tests worse than a 110-layer one, the opposite of the overfitting signature.

The identity-construction argument turns this observation into a proof of optimizer failure. Consider the 20-layer network that trains well. A 56-layer network contains it as a special case: copy the first 20 layers, then set every added layer to the identity mapping, and you reproduce the shallower solution exactly. So a deeper model can represent everything the shallower one can, plus more — its training error should be no worse, ever. When it is worse anyway, the extra capacity is not the problem; the solver's inability to discover the identity-like construction through a stack of nonlinear layers is. Any fix must therefore make identity-like mappings easy to find, not add capacity or regularization.

The Residual Reformulation: H(x) = F(x) + x

The residual block answers the identity-construction argument directly. Instead of asking a stack of layers to fit a desired mapping H(x), it fits the residual F(x) = H(x) − x and adds the input back through a parameter-free skip connection: y = F(x) + x. If the optimal mapping for a block is close to identity, the solver now drives the weights of F toward zero — pushing weights to zero is something SGD does naturally — rather than sculpting an identity matrix out of a cascade of ReLUs, which it empirically cannot. The skip adds no parameters and negligible compute, yet a 152-layer ResNet trained cleanly to 3.57% top-5 error on the ImageNet test set, winning ILSVRC 2015, at a depth where plain networks no longer train at all.

y = F(x, {Wi}) + x   ·   ∂L/∂x = ∂L/∂y · (∂F/∂x + 1)
The "+1" is the gradient highway: even if ∂F/∂x vanishes, the loss signal flows back undiminished.

Two refinements matter in practice. First, when block input and output dimensions differ (stride-2 downsampling, channel changes), the skip needs a projection shortcut — typically a 1×1 convolution — so the addition stays shape-compatible; identity shortcuts everywhere else, projections only where shapes force them. Second, the pre-activation variant (He et al., 2016, "Identity Mappings in Deep Residual Networks") moves batch normalization and ReLU before the convolution, so the skip path is a pure identity with no nonlinearity interrupting it; this is what lets 1000-layer residual networks train. The same highway logic explains a modern Transformer detail: large pre-LN models down-scale the residual-branch weights at initialization (GPT-2's famous 1/√(2·n_layers) factor), because dozens of additive blocks still compound variance even when each block starts near identity. 

# A residual block in PyTorch: the skip is the whole idea.
class BasicBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(channels)
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(channels)
        nn.init.zeros_(self.bn2.weight)  # gamma=0 -> F(x)=0 at init: block starts as identity

    def forward(self, x):
        f = self.conv2(torch.relu(self.bn1(self.conv1(x))))
        f = self.bn2(f)
        return torch.relu(f + x)  # residual + skip; gradient gets its +1 here

Shattered Gradients: Beyond Vanishing and Exploding

The vanishing/exploding gradient analysis is about gradient magnitude: signal that shrinks to zero or blows up as it backpropagates. Balduzzi et al. (2017, "The Shattered Gradients Problem") showed there is a second, independent failure — gradient structure. In a deep feedforward network, the gradients at nearby inputs decorrelate exponentially with depth: by layer 50–100, the gradient field resembles white noise, so a minibatch gradient step points in a direction that is essentially uncorrelated with the true descent direction at neighboring points. Careful initialization (Xavier, He) fixes the scale of the signal but not its correlation structure; a well-scaled white-noise gradient still cannot guide optimization.

Skip connections fix structure, not just scale. Each skip path carries the gradient back without passing it through another decorrelating nonlinearity, so the total gradient is an average over many paths of different lengths — and averaging correlated short-path gradients preserves correlation the way averaging independent noise does not. Balduzzi's framing: plain-network gradients shatter into white noise with depth, while residual-network gradients stay correlated (Brownian-like rather than white), which is why depth remains trainable. This is the correct answer when an interviewer asks what residuals buy you on top of good initialization and normalization: init sets the scale, skips preserve the direction.

ResNets Are Ensembles of Shallow Networks

Veit, Wilber & Belongie (2016, "Residual Networks Behave Like Ensembles of Relatively Shallow Networks") gave the trained model a complementary interpretation. Unravel the skips and an n-block ResNet is a collection of 2ⁿ paths of every length from 0 to n, with multiplicity C(n,k) for length k — a binomial distribution whose mass sits far below n. Because gradient magnitude decays with path length, the training signal flows overwhelmingly through the short paths: the effective depth of a 110-layer ResNet is a small fraction of its nominal depth, and most blocks contribute small refinements rather than indispensable transformations.

The lesion experiments make this concrete: delete any single residual block at test time and accuracy barely moves; randomly permute blocks and the network still functions. A plain chain would collapse under either intervention, but an ensemble degrades gracefully — removing one member never kills the committee. Huang et al. (2016) turned the view into a training method, stochastic depth: randomly drop whole blocks during training (keeping them all at test time), which shortens the expected training depth, cuts training time, and improves generalization — direct confirmation that the network trains as an ensemble and that most paths are expendable. The practical corollary: trained ResNets tolerate post-hoc block pruning and layer-dropping for faster inference far better than their depth suggests.

The Residual Stream: Iterative Refinement

The deepest framing generalizes beyond vision. Read a pre-LN Transformer as a residual architecture and every attention and MLP sublayer is an F(x) term reading from, and writing back to, one shared residual stream — the running sum all blocks append to (Elhage et al., 2021, "A Mathematical Framework for Transformer Circuits"). Layers are then not a pipeline of distinct representations but successive refinements of a single evolving state: each block queries the stream, computes an update, and adds it back. Because the stream path itself is a clean identity, information written by layer 2 is still directly readable by layer 40, which is what lets deep models implement multi-step, induction-like composition rather than one-shot feature extraction.

This reframes the residual connection as working memory. The stream carries hypotheses forward; attention heads move information between positions of the stream; MLP blocks transform what is there in place. Iterative-refinement behavior — early layers sketching a representation that late layers sharpen, with individual blocks ablatable at modest cost — falls out of the same ensemble-plus-highway mechanics as the vision case. When someone calls the residual stream the real legacy of the ResNet paper, this is the claim: skip connections stopped being a depth trick and became the communication fabric every deep architecture is built on.

Disambiguation for interviews. Vanishing gradients (signal scale, fixed by init/norms), shattered gradients (signal structure, fixed by skips), and degradation (optimizer failing at identity, diagnosed by worse training error at depth) are three different failures with three different signatures. Name which one you mean before proposing a fix.

Key Takeaways

  • Degradation is an optimizer failure, diagnosed by training error — He et al. showed a 56-layer plain CIFAR-10 net fits worse than a 20-layer one, and a 1202-layer net trains worse than a 110-layer one. Worse-train-plus-worse-test is the opposite of overfitting, and the identity-construction argument (extra layers could just be identity) proves the solver, not the capacity, is at fault.
  • The skip is a gradient highway you can verify in one line of PyTorch — y = F(x) + x gives ∂L/∂x = ∂L/∂y · (∂F/∂x + 1) no matter how small ∂F/∂x gets. Standard practice zero-initializes the last normalization scale of each branch (bn2.weight = 0 in torchvision-style ResNets, the equivalent Add() branch in TensorFlow/Keras) so every block starts life as an exact identity and only earns its nonlinearity.
  • Residuals fix gradient structure, init only fixes scale — Balduzzi et al. (2017) showed deep plain-network gradients decorrelate into white noise with depth, a failure Xavier/He initialization cannot address because it targets variance, not correlation. When an interviewer asks what skips add beyond good init and normalization, the answer is correlation preservation: JAX/Flax and PyTorch residual implementations alike train at depth because skip-averaging keeps gradients Brownian-like instead of white.
  • Train on the ensemble view to predict pruning and stochastic depth — Veit et al. (2016): 2ⁿ paths, binomial lengths, gradient concentrated in short paths, single-block lesions barely move accuracy. That is why stochastic depth (drop whole blocks while training, keep all at test) speeds training and helps generalization, and why post-hoc block pruning is a legitimate inference-latency lever on ResNet-family models.
  • The interview line, and where the idea lives now — "Degradation is optimization failure, proven by the identity-construction argument; skips fix it with a gradient highway; the trained net is an ensemble of mostly-shallow paths sharing one residual stream." In pre-LN Transformers that stream is the working memory every attention head and MLP reads and writes — residuals stopped being a depth trick and became the communication fabric, which is why depth-dependent residual scaling (GPT-2's 1/√(2·n_layers)) is still an init-level concern at 50+ blocks.
