Theory

The Transformer Stack

The Transformer, introduced in "Attention Is All You Need" (Vaswani et al., 2017), replaced the sequential processing of RNNs with fully parallel, attention-based computation. Every modern LLM — GPT, Llama, Mistral, Gemini — is built on this foundation or a close descendant. Understanding it deeply is table stakes for AI engineering.

1. Token Embedding

The model's input is a sequence of integer token IDs. Each ID is looked up in a learned embedding table of shape [vocab_size × d_model]. For GPT-3, vocab_size = 50,257 (BPE), d_model = 12,288. The embedding layer alone is ~600M parameters — a substantial fraction of smaller models. Crucially, embedding weights are often tied with the output projection at the end, halving parameter count without quality loss.

2. Positional Encoding

Self-attention is permutation-invariant by design — without explicit position information, the model cannot distinguish "dog bites man" from "man bites dog." Positional encodings (PEs) inject sequence order.

  • Sinusoidal (original paper): Fixed, not learned. PE(pos,2i) = sin(pos / 10000^(2i/d_model)). Generalizes to longer sequences than seen during training.
  • Learned Absolute (BERT, GPT-2): A trainable embedding table indexed by position. Simpler but fails to extrapolate beyond the training context length.
  • Rotary (RoPE — Llama, Mistral, GPT-NeoX): Encodes position by rotating Q and K vectors before dot product. Encodes relative position implicitly. Superior length generalization with YaRN or rope scaling.
  • ALiBi: Adds a linear attention bias based on distance. No position embeddings at all; inference-time extrapolation built-in.

3. Multi-Head Self-Attention (MHSA)

This is the heart of the transformer. For each layer, every token produces three projections — Query (Q), Key (K), and Value (V) — from learned weight matrices W_Q, W_K, W_V ∈ ℝ^(d_model × d_head). The attention score between position i and j is:

Attention(Q, K, V) = softmax( Q·Kᵀ / √d_k ) · V

The √d_k scaling prevents dot products from growing too large (which would push softmax into saturation). Multi-head attention splits d_model across h heads (typically d_head = d_model / h = 64), letting each head attend to different relational patterns. GPT-3 uses h = 96 heads across d_model = 12,288.

Causal masking sets all upper-triangular attention scores to -∞ before softmax, ensuring token i can only attend to positions ≤ i. This is what makes decoder-only models (GPT family) work — they never see future tokens during training.

Grouped-Query Attention (GQA) — used in Llama 3, Mistral — groups multiple Q heads to share a single K/V head. Reduces KV cache memory by 4–8× without meaningfully hurting quality. At the extreme, Multi-Query Attention (MQA) has a single shared K/V pair for all Q heads.

4. Feed-Forward Network (FFN)

After attention, each token is processed independently through a 2-layer MLP. The standard formulation:

FFN(x) = max(0, xW₁ + b₁)W₂ + b₂

The hidden dimension is typically 4× d_model (so 16,384 for d_model=4,096). Modern LLMs use SwiGLU instead of ReLU:

FFN_SwiGLU(x) = (SiLU(xW₁) ⊙ xW₃) · W₂

SwiGLU was found to outperform ReLU and GeLU empirically (PaLM, Llama). It uses 3 projection matrices instead of 2, but the inner dimension is typically scaled to 2/3 × 4d to keep parameter count equivalent.

5. Residual Connections & Layer Normalization

Each sub-layer (attention, FFN) is wrapped in a residual connection: output = LayerNorm(x + sublayer(x)). Residuals enable stable training of deep networks by providing gradient highways that bypass sub-layers.

The original paper uses Post-LN (norm after residual addition). Most modern LLMs use Pre-LN (norm before each sub-layer), which trains more stably without requiring careful learning rate warmup. Llama uses RMSNorm instead of LayerNorm — it omits the mean-centering step, saving ~40% of the norm computation with no quality regression.

6. Stacking N Layers

A complete transformer decoder is N identical blocks, each containing: Pre-LN → MHSA → residual → Pre-LN → FFN → residual. Depth (N) and width (d_model) are the primary scaling dimensions. GPT-2 Small has 12 layers / d=768; GPT-3 has 96 layers / d=12,288; Llama 3 70B has 80 layers / d=8,192.

7. Output Projection (LM Head)

The final hidden state of each position is projected back to vocab_size logits via a linear layer (often weight-tied with the embedding table). A softmax converts logits to probabilities for sampling or loss computation.

Production Reality: Parameter Counts & Compute

For a decoder-only transformer: total parameters ≈ 12 × N × d² + vocab × d. This scales quadratically with width. Compute for one forward pass ≈ 2P FLOPs (where P is parameter count). A 70B model requires ~140B FLOPs per forward pass token — at A100 peak (312 TFLOPS), one token takes ~0.45ms on a single GPU, requiring 4× A100 to hit 140B/s sustained throughput at a practical batch size.

The attention complexity is O(n²·d) per layer for sequence length n. For context windows beyond 32K, this becomes the limiting factor. Flash Attention (Dao et al., 2022) fuses operations in SRAM to reduce memory I/O from O(n²) to O(n), making 128K+ context practical.

Key Takeaways

What Senior Engineers Know

  • Pre-LN vs Post-LN matters at scale: Post-LN (original paper) causes gradient explosion in very deep networks without careful warmup. Modern LLMs universally use Pre-LN or RMSNorm + Pre-LN, making training stable from the first step.
  • The FFN dominates parameter count: In a standard 4× FFN, two-thirds of all non-embedding parameters live in the FFN layers. Reducing FFN width (e.g., from 4d to 2.67d with SwiGLU) cuts parameters significantly while maintaining quality — which is why Llama does it.
  • Attention is O(n²) but Flash Attention hides the constant: Flash Attention 2 achieves ~50% of A100 peak FLOPs by keeping tiles in SRAM. This is why 128K context windows are now practical; without it, the memory writes to HBM would dominate.
  • GQA is the free lunch for inference: Grouped-Query Attention (used in Llama 3, Mistral) reduces KV cache from O(N·h·n·d) to O(N·(h/g)·n·d) where g is the group size. For 8B models at batch=1 with 8K context, this saves ~2 GB of KV cache — often the difference between fitting on one GPU or two.
  • Weight tying is non-obvious but universal: Tying embedding and LM head weights (vocab × d_model) saves 0.3–1.5B parameters for large-vocab models and slightly regularizes training by enforcing semantic alignment between input and output spaces.
  • RoPE's real advantage is YaRN-style context extension: Learned absolute PEs hard-cap the context window. RoPE + YaRN (or linear scaling) lets you extend a 4K-context model to 128K post-hoc with minimal fine-tuning — the key technique behind Llama's context extension from 4K to 128K in Llama 3.
