The ARCH Framework

Four components with specific things to mention

A Architecture — Components & Data Flow

What pieces exist and how they connect

What to Mention Example
Components Briefing Agent, Text Agent, Image Agent, Video Agent, Assembly Agent, Asset Manager, Review/Approval System
Data Flow User Prompt → Briefing → [Text, Image, Video in parallel] → Assembly → Review/Approval → Final Asset
Agents Specialized agents: Briefing (extracts requirements), Text (writes copy), Image (generates/edits images), Video (creates clips), Assembly (combines into final format)
Services LLM API (text generation), Image Gen API (DALL-E/Midjourney), Video Gen API (Runway/Pika), Asset Store (S3/Cloudinary), Review DB (PostgreSQL), Queue (Redis/RabbitMQ)
State Management User prompt (initial), Generated assets (temporary), Final output (persistent), Revision history (versioned), Approval status (workflow)
Key line: "We have five specialized agents: Briefing (extracts requirements from prompt), Text (generates copy), Image (generates visuals), Video (creates clips), and Assembly (combines into final format). Image and Video agents run in parallel to reduce total generation time."

R Routing — Agent Orchestration

How agents run and communicate

What to Mention Example
Agent Orchestration Sequential briefing → parallel generation → sequential assembly → review loop; dependency chain: Assembly waits for all generation agents
Communication Pattern Workflow orchestrator (Temporal/Cadence) manages dependencies; message queue for async generation; shared state for asset references
Decision Logic Briefing Agent decides what to generate; Assembly Agent determines layout/style; Review Agent checks brand compliance; Human approver has final say
Key line: "Agents run in a hybrid pattern: Briefing is sequential, generation is parallel, assembly is sequential. Workflow orchestrator (e.g., Temporal) manages dependencies and retries."

C Constraints — What Can Break

Failure modes, limits, and edge cases

What to Mention Example
Style Consistency Use shared style guide (hex codes, fonts, tone); prompt engineering for consistency; brand asset library; human review for final approval
Revision Loops Store intermediate assets; enable partial regeneration (only change text, not image); version history; rollback capability
Cost Optimization Cache generated assets; use cheaper models for drafts; only use expensive models for final; batch similar requests; resize/compress before storage
Length Limits Token limits for text; frame limits for video; dimension limits for images; enforce via validation before generation
Asset Ownership Clear IP licensing; usage rights tracking; watermarking for drafts; full ownership transfer on final approval
Key line: "We maintain style consistency via shared brand asset library and prompt engineering. Revision loops store intermediate assets for partial regeneration. Costs are optimized by caching, using cheaper models for drafts, and batching."

H Heuristics — Why This Design

Trade-offs, scaling, and decisions

What to Mention Example
Why This Architecture? Separate agents allow expertise per modality; parallel generation reduces latency; assembly layer ensures consistency
Why Not X? Single multimodal model would lack fine-grained control; no assembly layer would risk inconsistent outputs; no review layer would risk brand safety
Scaling Path Queue-based generation for high volume; CDN for asset delivery; quantized models for cost reduction; edge caching for frequently used brand assets
Monitoring Track generation latency, cost per asset, style consistency scores, revision frequency, human approval rates, asset reuse rates
Key line: "I chose separate specialized agents for each modality to allow fine-grained control and independent optimization. The assembly layer is critical for maintaining brand consistency across text, image, and video."

E Evaluation — How We Measure Success

Offline benchmarks, online metrics, and per-agent KPIs

Type Metric Target / Example
Offline Style consistency > 90% brand guideline adherence (human rated); Color/font alignment 100%
Offline Content quality BLEU/ROUGE scores for text; FID score < 50 for images; human rating > 4/5 for video
Offline Revision accuracy > 80% of revisions correctly interpreted; partial regeneration success > 95%
Online Generation latency Text < 3s; Image < 10s; Video < 60s; Full asset < 90s (p95)
Online Cost per asset Text < $0.01; Image < $0.05; Video < $0.50; Batch processing reduces by 30%
Online Throughput > 1000 assets/hour; handle Black Friday spikes (10x normal)
Per-Agent Text Agent Grammar accuracy > 99%; Brand voice alignment > 90%; Length compliance 100%
Per-Agent Image Agent Prompt adherence > 95%; Resolution compliance 100%; Format compliance 100%
Per-Agent Video Agent Clip coherence > 90%; lip-sync accuracy > 85%; Duration compliance 100%
System Human approval rate First-pass approval > 70%; Revision cycles < 2 per asset
System Brand safety Zero brand safety incidents; 100% asset ownership clarity; All watermarks removed on final
Key line: "We evaluate offline on brand guideline adherence (> 90%) and content quality (FID < 50 for images). Online, we track generation latency (p95 < 90s), cost per asset, and throughput (> 1000/hour). First-pass human approval > 70%."
