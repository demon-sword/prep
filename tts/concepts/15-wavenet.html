15WaveNet and Autoregressive Audio

The model that proved you could generate a waveform sample by sample and have it sound like a person. Dilated causal convolutions buy 192 ms of context from 30 layers instead of 3,000. Then the bill: one forward pass per sample, 16,000 per second of audio, strictly in order — which is why every production vocoder since has worked to get rid of the “in order” part.

Theory

The waveform as a product of conditionals

WaveNet (van den Oord et al., DeepMind, 2016) throws away the spectrogram and factorises the raw signal: p(x) = ∏t p(xt | x1…xt−1). Every sample is predicted from all the samples before it. The head is not a regression onto a real number but a 256-way softmax: the waveform is first passed through mu-law companding at µ = 255 and quantised to 8 bits — the same companding law G.711 applies on a phone trunk. Classification beats regression for the reason cross-entropy beats MSE on multimodal targets: at a glottal closure the next sample is genuinely bimodal, and a Gaussian head averages the modes into a click.

One number from the paper's listening test is worth carrying: natural speech requantised to 8-bit mu-law scored 4.46 MOS against 4.55 for 16-bit linear PCM. Their raters, their test set — but it prices the quantisation a PSTN leg imposes for free at about a tenth of a MOS point.

Dilated causal convolutions

Causal means the output at t sees only inputs up to t: in practice a left-shifted convolution. Stack plain causal convolutions with kernel 2 and the receptive field grows by one sample per layer, so 200 ms of context at 16 kHz needs about 3,200 of them. WaveNet doubles the dilation instead: 1, 2, 4, … 512, then repeats the block. For kernel k over dilations di, R = 1 + ∑(k−1)·di, so one ten-layer block gives 1 + 1023 = 1024 samples and the paper's example of three such blocks — 30 layers — gives 3,070 samples, about 192 ms at 16 kHz. Linear depth, exponential context.

Each layer is a gated unit, z = tanh(Wf∗x) ⊙ σ(Wg∗x), with a residual path so gradients reach layer 1 and a skip path summed across all layers into the output 1×1 convolutions. Conditioning is where TTS enters: a global speaker embedding added to every layer's pre-activation, and local conditioning on linguistic features or F0, upsampled from frame rate to sample rate. That local path is the interface a modern vocoder uses when you hand it 80-bin mel at a 256-sample hop.

Why nobody serves it

Training parallelises — teacher forcing computes every timestep at once. Inference does not: sample t+1 needs sample t, so it is one full forward pass per sample. 16,000 passes per second of audio at 16 kHz, 24,000 at 24 kHz, 8,000 on a narrowband telephony leg. Worse, the naive implementation recomputes the whole dilated tree every step. Fast WaveNet (Paine et al., 2016) removes it with a per-layer FIFO queue of length equal to that layer's dilation, so each step is one two-tap convolution per layer. On a typical open-source configuration — 64 residual, 256 skip channels — that is roughly 1.1 M MACs per sample, about 18 GMAC/s: trivial arithmetic for any modern accelerator.

The cost is not arithmetic, it is sequential dependency. Thirty layers × 16,000 samples is 480,000 strictly ordered kernel launches per second of audio; at 5 µs of launch and memory latency each, that alone is 2.4 s of wall clock per second of audio — RTF 2.4 before a single useful FLOP. Batching multiplies throughput and does nothing for per-call latency, which is the wrong shape for a voice agent: in an 800 ms turn budget where TTS gets on the order of 100 ms of time-to-first-audio, an RTF above 1 does not merely miss the budget — the model can never keep up with playback at all.

The failure mode, and what replaced it

Trained unconditionally, or with the conditioning effectively ignored, an autoregressive sample model babbles: fluent, correctly-timbred, phonetically plausible non-language, because nothing ties it to the text. Errors compound — a bad sample feeds straight back in — so the characteristic artefact is a rasp or crackle that grows across the utterance rather than a uniform hiss.

Two escapes. Parallel WaveNet (2017) distils the autoregressive teacher into an inverse-autoregressive-flow student by probability density distillation, turning generation into one parallel pass; that is the version that shipped in Google Assistant. GAN vocoders such as HiFi-GAN drop the density model for a feed-forward generator. WaveNet's residual block never went away: it is the posterior encoder in VITS and the backbone of several neural codecs. One compliance note: this is a likelihood model trained on raw caller waveform, and assigning explicit probabilities to sequences makes membership inference more tractable than against a discriminative model. Treat the checkpoint as PHI-derived.

Visualization — the context is exponential, the cost is not

# ---- receptive field: linear depth, exponential context --------------------
k, blocks, per_block = 2, 3, 10
dil = [2**i for i in range(per_block)] * blocks   # 1,2,4,...,512  x3
R   = 1 + sum((k - 1) * d for d in dil)           # 1 + 3*1023 = 3070 samples
ms  = 1000 * R / 16000                            # 191.9 ms of context, 30 layers
# a PLAIN causal stack (dilation 1) would need R - 1 = 3069 layers for the same

# ---- one cached step: Fast WaveNet's FIFO trick ----------------------------
def step(x_t, q):                 # q[l] = deque(maxlen=dil[l]) -- the only state
    h, skips = x_t, 0
    for l, d in enumerate(dil):
        x_past = q[l].popleft(); q[l].append(h)   # the single tap, d samples back
        a = W_f[l][0] @ x_past + W_f[l][1] @ h    # filter branch, 2 taps
        b = W_g[l][0] @ x_past + W_g[l][1] @ h    # gate branch, 2 taps
        z = tanh(a) * sigmoid(b)                  # gated activation unit
        skips += W_skip[l] @ z                    # 64 -> 256
        h     = h + W_res[l] @ z                  # residual, 64 -> 64
    return softmax(W_2 @ relu(W_1 @ relu(skips))) # 256 mu-law bins, argmax/sample it

The line I'd actually say

"WaveNet models the waveform directly as a product of per-sample conditionals, with a 256-way softmax over mu-law bins rather than a regression — which matters because the next sample at a glottal closure is bimodal and an L2 head would average it into a click. The trick that made it tractable is dilated causal convolution: doubling the dilation each layer means 30 layers buy you about 3,000 samples of context, roughly 190 ms at 16 kHz, where a plain causal stack would need 3,000 layers."

"The reason it isn't a production vocoder is one forward pass per sample — sixteen thousand strictly sequential passes per second of audio. The arithmetic is nothing, about 18 GMAC/s with cached queues; it's the serialisation that kills you. Thirty layers times sixteen thousand samples is nearly half a million ordered kernel launches per second of audio, so you're paying launch latency, not FLOPs, and batching buys throughput while doing nothing for the one call you're on. That's exactly why Parallel WaveNet distilled it into an IAF student and why HiFi-GAN dropped the density model for a feed-forward generator. I'd still teach WaveNet, though — its residual block is sitting inside VITS and inside most neural codecs."

Takeaways

  • Softmax over mu-law bins, not a regression. 8-bit µ = 255 companding — the G.711 law — gives 256 classes, which lets the model represent a genuinely bimodal next sample instead of averaging it into a click. The paper's own raters put 8-bit mu-law natural speech at 4.46 MOS against 4.55 for 16-bit linear, so the phone network's quantisation costs about 0.1 MOS on its own.
  • Dilation buys context at linear depth. R = 1 + ∑(k−1)di: ten layers with dilations 1–512 give 1,024 samples, three such blocks give 3,070 — ~192 ms at 16 kHz from 30 layers, where an undilated stack needs 3,069. Blocks reset the dilation so the deep layers still see fine local structure.
  • The wall is serialisation, not FLOPs. ~1.1 M MACs per sample is nothing; 480,000 strictly ordered kernel launches per second of audio is everything. Profile launch latency, not utilisation — in PyTorch that means CUDA graphs or a fused persistent kernel, and exporting to ONNX for Triton will not fix an RTF that is dominated by the dependency chain.
  • Cache the queues or pay exponentially. Fast WaveNet's per-layer FIFO of length di turns each step into one two-tap convolution per layer; naive re-evaluation of the dilated tree is the classic mistake, and its cost grows exponentially with depth.
  • Its failure mode is babble, and it compounds. Weak conditioning gives fluent, well-timbred non-language; sampling errors feed straight back in, so artefacts grow across an utterance instead of staying uniform. Emit per-utterance RTF and a rolling spectral-flatness metric to Prometheus — a drifting crackle shows up there before a caller reports it.
  • It lost as a vocoder and won as a component. Parallel WaveNet distilled it into a one-pass IAF student and HiFi-GAN abandoned density modelling altogether, but WaveNet residual blocks are the posterior encoder in VITS and the backbone of several neural codecs. On telephony, note that 8 kHz halves the sequential step count outright — the one lever narrowband hands you for free.
