JS this Keyword

Implicit · Explicit · new Binding · Arrow Functions · Priority Rules

CORE CONCEPT What Determines this?
▼

The value of this is determined by how a function is called, not where it is defined.

Quick Rule

Look to the left of the dot where the function is called: obj.method() means this is obj.

MUST KNOW The 4 Rules (Priority Order)
▼
PriorityRuleExamplethis Value
1 new binding new Person() The new object instance
2 Explicit fn.call(obj) / fn.apply(obj) / fn.bind(obj) The object passed as first arg
3 Implicit obj.method() The object before the dot (obj)
4 Default func() window (browser) or global (Node.js). Strict mode: undefined
TRICKY Arrow Functions
▼

Arrow functions do not have their own this. They inherit this from the enclosing (parent) scope.

const obj = { 'name': 'Alice', 'regular': function() { console.log(this.name); // "Alice" }, 'arrow': () => { console.log(this.name); // undefined (inherits from outer scope) } };
PRACTICE Interview Questions
▼
Q1: What is logged?
const obj = { 'value': 42, 'getValue': function() { return this.value; } }; const getValue = obj.getValue; console.log(obj.getValue()); // ? console.log(getValue()); // ?

obj.getValue() -- 42 (implicit binding)

getValue() -- undefined (default binding)

Q2: Fix the setTimeout bug
const button = { 'text': 'Click me', 'click': function() { setTimeout(function() { console.log(this.text); // undefined }, 100); } };

Problem: Regular function in setTimeout has its own this (window).

Fix: Use arrow function.

setTimeout(() => { console.log(this.text); // "Click me" }, 100);
Q3: What is the output?
const person = { 'name': 'John', 'sayHi': () => { console.log(`Hi, I am ${this.name}`); } }; person.sayHi();

"Hi, I am undefined"

Arrow function does not bind its own this, so it looks to the outer scope.

Q4: What is the output?
function User() { this.name = 'Alice'; setTimeout(function() { console.log(this.name); }, 10); } new User();

undefined -- setTimeout callback is a regular function, so this defaults to window. Fix with arrow function or .bind(this).
