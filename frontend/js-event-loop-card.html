JS Event Loop

Call Stack - Microtask Queue - Macrotask Queue - Execution Order

BASICS What Goes Into Each Queue?
▼
QueueSourcesPriority
Call Stack console.log, function calls, loops Highest
Microtask .then(), .catch(), await High (drain all)
Macrotask setTimeout, setInterval, I/O Lower (one at a time)
